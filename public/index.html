    Try, compare, explain.

    Compare a configuration with temperature omitted to one that supplies it. Check your model's current provider documentation before making the live call.

    01

    Separate provider and model

    A provider account supplies access; a model identifier selects a model. A single provider can offer multiple models.

    02

    Validate the selected route

    The provider field must agree with the provider/model identifier. The configured credential must belong to that selected provider.

    03

    Bound classroom generation

    The application checks its own output-token and temperature ranges. These are lab policies, not universal provider capability guarantees.

    04

    Treat temperature carefully

    Temperature does not guarantee truth or determinism. Omit it when the selected model does not support the setting.

    05

    Record what is pinned

    The package lockfile pins installed packages. A model alias may still change remotely; record the exact identifier used.

    06

    Measure rather than invent

    Inspect real errors and task outcomes. This app makes no unsupported claims about comparative model quality, price or latency.
